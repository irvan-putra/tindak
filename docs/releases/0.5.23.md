# tindak 0.5.23

The list no longer shows old rows. Completed, canceled, archived and deleted items are hidden, and an item repeated in the feed shows once. The widget gets the same active-only list.

The home screen now groups items under the section titles from your feed, each with a count. Empty groups are hidden.

New in the menu: "Show history (finished items)" lists only the finished rows, and "Back to active items" returns. History is a view only, nothing is deleted.

The launcher icon is now a single full-color 192px image, no density set, no adaptive or monochrome layer. Launchers may cache the old icon; a reinstall or reboot refreshes it.

Same-install update over 0.5.22. Existing feed address, pairing key and cache stay unchanged. No new permissions or signing-key change.

Four new unit tests cover the filtering and grouping; the full suite (155 tests) passed on CI. Not yet checked on a physical phone.
